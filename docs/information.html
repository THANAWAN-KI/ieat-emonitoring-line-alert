IEAT EMCC • GIS INFORMATION CENTER

ระบบสารสนเทศและการเชื่อมโยงข้อมูล GIS

ศูนย์กลางการบูรณาการข้อมูลเชิงพื้นที่ เพื่อเฝ้าระวังสิ่งแวดล้อม ติดตามสถานการณ์น้ำ และสนับสนุนการบริหารความเสี่ยงของนิคมอุตสาหกรรมทั่วประเทศ

01 • INTEGRATED GIS

ข้อมูลระบบสารสนเทศและการเชื่อมโยงข้อมูลระบบ GIS

รวบรวมชั้นข้อมูลจากหลายระบบให้อยู่บนแผนที่เดียวกัน ช่วยให้ผู้บริหารและผู้เยี่ยมชมเห็นภาพรวมของพื้นที่นิคมอุตสาหกรรม โครงสร้างพื้นฐาน ข้อมูลประกอบการอนุญาต และทรัพยากรสำหรับรับมือเหตุฉุกเฉินได้อย่างเข้าใจง่าย

เหมาะสำหรับนำเสนอภาพรวมการทำงานของศูนย์ฯ

ชั้นข้อมูลที่เชื่อมโยงบนแผนที่

ข้อมูลแบบ CADแปลงผังและขอบเขตพื้นที่ให้อยู่ในรูปแบบข้อมูล GIS
ระบบ e‑PPข้อมูลผู้ประกอบการและข้อมูลที่เกี่ยวข้องภายในนิคมฯ
ระบบ DSSข้อมูลสนับสนุนการตัดสินใจและรายละเอียดพื้นที่
ภาวะฉุกเฉินจุดสำคัญและทรัพยากรเพื่อสนับสนุนการตอบโต้เหตุ

แผนที่ข้อมูลบูรณาการ กนอ.

เลือกชั้นข้อมูล เปิดคำอธิบายสัญลักษณ์ หรือค้นหาพื้นที่ที่ต้องการบนแผนที่

เปิดคลังข้อมูล DSSเปิดเต็มหน้าจอ
การใช้งาน: เปิด–ปิดชั้นข้อมูลจาก Legend และคลิกพื้นที่เพื่อดูรายละเอียดหากแผนที่ไม่แสดง ให้เปิดหน้าต่างใหม่
02 • ENVIRONMENTAL MONITORING

Dashboard e‑Monitoring

แสดงผลการตรวจวัดคุณภาพอากาศภายในพื้นที่นิคมอุตสาหกรรมที่ กนอ. กำกับดูแล เพื่อเฝ้าระวังค่าสิ่งแวดล้อม ตรวจสอบสถานะสถานี และเชื่อมต่อข้อมูลสำคัญไปยังระบบแจ้งเตือนผ่าน LINE

จากข้อมูลตรวจวัด สู่การเฝ้าระวังและแจ้งเตือน

ประโยชน์ในการติดตามสถานการณ์

คุณภาพอากาศแสดงผลตรวจวัดจากสถานีในพื้นที่นิคมอุตสาหกรรม
ตำแหน่งสถานีตรวจสอบจุดติดตั้งและพื้นที่รับผิดชอบบนแผนที่
สถานะข้อมูลใช้ประกอบการตรวจสอบสถานีและความต่อเนื่องของข้อมูล
แจ้งเตือน LINEส่งข้อมูลที่ต้องเฝ้าระวังไปยังกลุ่มผู้รับที่เกี่ยวข้อง

แผนที่สถานีตรวจวัด e‑Monitoring

ดูตำแหน่งสถานีและข้อมูลตรวจวัดคุณภาพอากาศในพื้นที่นิคมอุตสาหกรรม

รายงานสถานีเปิดเต็มหน้าจอ
ขอบเขตข้อมูล: สถานีตรวจวัดคุณภาพสิ่งแวดล้อมของนิคมอุตสาหกรรมที่ กนอ. ดูแลเปิดหน้าสรุป e‑Monitoring
03 • WATER LEVEL WATCH

Dashboard ข้อมูลระดับน้ำกรมชลประทาน

นำข้อมูลระดับน้ำจากกรมชลประทานมาแสดงผลในมุมมองเชิงพื้นที่ โดยเน้นสถานีและพื้นที่ที่อยู่ภายในหรือใกล้นิคมอุตสาหกรรม เพื่อช่วยคัดกรองสถานการณ์ที่ควรติดตามและสนับสนุนการเตรียมความพร้อม

โฟกัสพื้นที่นิคมฯ และบริเวณใกล้เคียง

ข้อมูลที่ใช้ประกอบการเฝ้าระวัง

ระดับน้ำติดตามค่าระดับน้ำจากสถานีของกรมชลประทาน
พื้นที่ใกล้นิคมฯคัดเลือกสถานีที่มีความสัมพันธ์กับพื้นที่รับผิดชอบ
แนวโน้มสถานการณ์ใช้ข้อมูลล่าสุดประกอบการประเมินและติดตามต่อเนื่อง
เตรียมความพร้อมสนับสนุนการประสานงานเมื่อพบพื้นที่ที่ควรเฝ้าระวัง

สถานการณ์น้ำและพื้นที่เฝ้าระวัง

ข้อมูลระดับน้ำและเครื่องมือสนับสนุนการติดตามพื้นที่นิคมอุตสาหกรรม

ข้อมูลต้นทางกรมชลประทานเปิดเต็มหน้าจอ
หมายเหตุ: ข้อมูลใช้เพื่อการเฝ้าระวังเบื้องต้น ควรตรวจสอบร่วมกับประกาศทางการและข้อมูลภาคสนามเปิดรายงานสถานการณ์น้ำ
04 • ACCIDENT STATISTICS

Dashboard สรุปข้อมูลสถิติอุบัติเหตุ

นำข้อมูลตำแหน่งการเกิดอุบัติเหตุมาวิเคราะห์และสรุปเป็นภาพรวม เพื่อดูการกระจายตัวของเหตุการณ์ ค้นหาพื้นที่ที่เกิดเหตุซ้ำ และใช้ประกอบการกำหนดมาตรการป้องกันความเสี่ยงในนิคมอุตสาหกรรม

เปลี่ยนข้อมูลเหตุการณ์ให้เป็นข้อมูลเพื่อการตัดสินใจ

แนวทางพัฒนาเป็น Dashboard ของศูนย์ฯ

จำนวนเหตุการณ์สรุปจำนวนอุบัติเหตุตามช่วงเวลาและประเภทเหตุ
พื้นที่เกิดเหตุแสดงตำแหน่งและการกระจายตัวบนแผนที่
ตัวกรองนิคมฯเลือกดูข้อมูลเฉพาะนิคมอุตสาหกรรมที่ต้องการ
แนวโน้มความเสี่ยงใช้สถิติสนับสนุนมาตรการป้องกันและแผนงาน

แผนที่ข้อมูลอุบัติเหตุ

แผนที่ฐานสำหรับพัฒนาตัวชี้วัด กราฟสรุป และตัวกรองใน Dashboard ของศูนย์ฯ

ดู Dashboard ตัวอย่างเปิดเต็มหน้าจอ
ขั้นต่อไป: สร้าง Dashboard ของศูนย์ฯ จาก Web Map นี้ พร้อมตัวเลขสรุป กราฟ และตัวกรองตามนิคมฯเปิดตัวอย่างอ้างอิง
