คู่มือความปลอดภัย

สำหรับผู้ประกอบการและพนักงานในนิคมอุตสาหกรรม

ใช้เป็นแนวทางเบื้องต้นเมื่อเกิดเหตุ ให้ปฏิบัติตามแผนฉุกเฉินของสถานประกอบการและคำสั่งของผู้ควบคุมเหตุเป็นอันดับแรก

เมื่อพบเหตุผิดปกติ ให้ทำ 3 ขั้นตอนนี้

1
หยุดหยุดงานและออกจากพื้นที่เสี่ยงอย่างปลอดภัย
2
แจ้งแจ้งหัวหน้างาน ห้องควบคุม หรือทีมฉุกเฉินทันที
3
อพยพไปยังจุดรวมพลตามเส้นทางที่กำหนด

คู่มือปฏิบัติเมื่อเกิดเหตุ

ไฟไหม้ / ควัน / กลิ่นไหม้
  1. กดสัญญาณแจ้งเหตุหรือแจ้งผู้ควบคุมพื้นที่ทันที
  2. หากเป็นไฟขนาดเล็กและผ่านการอบรมแล้ว จึงใช้ถังดับเพลิงชนิดที่เหมาะสม
  3. ห้ามเสี่ยงเข้าควบคุมไฟ หากควันหนา ไฟลุกลาม หรือไม่แน่ใจ
  4. อพยพตามป้ายทางหนีไฟ ห้ามใช้ลิฟต์ และไปยังจุดรวมพล
ห้ามกลับเข้าอาคารจนกว่าจะได้รับอนุญาตจากผู้ควบคุมเหตุ
สารเคมีรั่วไหล / กลิ่นผิดปกติ
  1. หยุดงานและแจ้งผู้บังคับบัญชา ทีม ERT หรือห้องควบคุม
  2. อย่าสัมผัส สูดดม หรือเดินผ่านบริเวณที่มีสารรั่วไหล
  3. ออกจากพื้นที่โดยอยู่เหนือลมหรือทิศทางที่ปลอดภัย
  4. หากสัมผัสสาร ให้ใช้ฝักบัวนิรภัยหรือที่ล้างตาตาม SDS ของสาร และพบแพทย์
ห้ามใช้น้ำหรือวัสดุดูดซับเอง หากไม่ทราบชนิดสารหรือไม่ได้รับมอบหมาย
การอพยพและจุดรวมพล
  • ฟังประกาศจากระบบเสียงตามสาย ผู้ประสานงาน หรือหัวหน้างาน
  • เดินเร็วแต่ไม่วิ่ง ไม่ผลักกัน และช่วยผู้ที่ต้องการความช่วยเหลือ
  • ไปยังจุดรวมพลที่กำหนด แล้วรายงานตัวกับหัวหน้างาน
  • ห้ามแยกตัวออกจากกลุ่ม หรือกลับไปเก็บของส่วนตัว
ผู้บาดเจ็บหรือเจ็บป่วยฉุกเฉิน
  1. แจ้งทีมปฐมพยาบาลหรือโทร 1669
  2. อย่าเคลื่อนย้ายผู้บาดเจ็บ เว้นแต่พื้นที่นั้นยังไม่ปลอดภัย
  3. บอกตำแหน่งเกิดเหตุ อาการ จำนวนผู้บาดเจ็บ และจุดนัดพบรถพยาบาลให้ชัดเจน
  4. ให้เฉพาะผู้ผ่านการฝึกอบรมทำ CPR หรือปฐมพยาบาล

เบอร์ฉุกเฉิน

1669การแพทย์ฉุกเฉิน 199แจ้งเหตุเพลิงไหม้ 191เหตุด่วนเหตุร้าย 1784สายด่วนสาธารณภัย 02-207-2700Call Center กนอ. สำนักงานนิคมฯค้นหาเบอร์ติดต่อพื้นที่

ตรวจสอบก่อนเริ่มงาน

  • สวม PPE ให้เหมาะกับงานและอยู่ในสภาพพร้อมใช้
  • รู้ตำแหน่งทางหนีไฟ จุดรวมพล ถังดับเพลิง ที่ล้างตา และฝักบัวนิรภัย
  • อ่าน SDS และขั้นตอนปฏิบัติงานก่อนใช้สารเคมีหรือเครื่องจักร
  • แจ้งหัวหน้างานทันทีเมื่อพบการรั่วไหล เครื่องจักรผิดปกติ หรือสภาพไม่ปลอดภัย
  • ไม่ทำงานนอกเหนือจากหน้าที่หรือขั้นตอนที่ได้รับอนุญาต
คู่มือนี้เป็นข้อมูลเบื้องต้น ไม่ทดแทนแผนฉุกเฉินของสถานประกอบการ การฝึกอบรม หรือคำสั่งของเจ้าหน้าที่ในพื้นที่
