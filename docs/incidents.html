รับแจ้งเหตุและรายงาน

รับแจ้ง → เลือกโรงงานและข้อมูลสนับสนุน → จัดทำรายงาน → ติดตามหลังเกิดเหตุ

รายงานเดิมที่บันทึก

รุ่นทดลอง: รายการเหตุและรายงานเก็บในเบราว์เซอร์นี้ ยังไม่ใช่ทะเบียนเหตุส่วนกลางของหน่วยงาน

สร้างรายการรับแจ้ง

เลือกประเภทเหตุ → บันทึก → ตรวจแบบรายงานเฉพาะภัย → ดาวน์โหลด PNG
