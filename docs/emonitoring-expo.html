02 / Recognition

Recognition

ผู้ได้รับรางวัลในการประกวดของ Esri มีโอกาสได้รับการเผยแพร่ผลงานและการยอมรับจากชุมชนด้านภูมิสารสนเทศทั่วโลก

  • ประกาศนียบัตรจาก Esri
  • การเผยแพร่ผลงานบนเว็บไซต์ Esri
  • การยกย่องผลงานในการประชุม Esri User Conference
  • สิทธิประโยชน์อื่น ๆ ตามเงื่อนไขการแข่งขัน
03 / Requirements

Requirements

การแข่งขันเปิดรับผลงานจากผู้สมัครอายุ 18 ปีขึ้นไปทั่วโลก โดยมีหมวดหัวข้อให้เลือกและรูปแบบการสมัครเป็นไปตามเกณฑ์ของผู้จัด

  • ผลงานต้องสร้างด้วย ArcGIS StoryMaps
  • เลือกส่งผลงานในหนึ่งในสี่หมวดการแข่งขัน
  • มีประเภทสำหรับนักศึกษา
  • ศึกษาข้อกำหนดการส่งผลงานจากเว็บไซต์ทางการ
See official requirements ↗
04 / Judging criteria

Judging criteria

ผลงานจะได้รับการพิจารณาโดยคณะกรรมการและผู้เชี่ยวชาญ โดยเน้นคุณค่าของการเล่าเรื่องผ่านข้อมูลและพื้นที่ พร้อมรางวัลสำหรับผลงานโดดเด่นในหมวดการแข่งขัน

การออกแบบเรื่องราวควรนำเสนอประเด็นที่ชัดเจน มีข้อมูลที่น่าเชื่อถือ สื่อสารง่าย และใช้แผนที่ในบทบาทที่ช่วยให้เกิดความเข้าใจใหม่
