สำหรับประชาชนในพื้นที่

เลือกนิคมฯ หรือค้นหาสถานีใกล้พื้นที่ที่สนใจ ตรวจสอบค่าที่มีและเวลาตรวจวัด หากพบเหตุผิดปกติ สามารถใช้ช่องทางรับแจ้งเหตุของระบบเพื่อส่งรายละเอียดให้ผู้เกี่ยวข้องตรวจสอบ
