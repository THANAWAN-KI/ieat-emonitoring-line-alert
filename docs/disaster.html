น้ำท่วม / น้ำป่าไหลหลาก

ติดตามแผนที่น้ำท่วมจากภาพดาวเทียม และระบบคาดการณ์พื้นที่เสี่ยงน้ำท่วมฉับพลัน

แผนที่น้ำท่วม GISTDAคาดการณ์น้ำป่า

ฝนหนัก / พายุ / คลื่นลม

ติดตามประกาศเตือนภัย พยากรณ์อากาศ เรดาร์ และเส้นทางพายุจากกรมอุตุนิยมวิทยา

กรมอุตุนิยมวิทยาเรดาร์และแผนที่

แผ่นดินไหว / สึนามิ

รายงานแผ่นดินไหวศูนย์เตือนภัย ปภ.

ไฟป่า / จุดความร้อน / หมอกควัน

ดูจุดความร้อนและพื้นที่เฝ้าระวังไฟป่าจากข้อมูลดาวเทียมของ GISTDA
