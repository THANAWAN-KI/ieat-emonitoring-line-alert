-จำนวนเหตุการณ์ทั่วโลก
-เหตุการณ์ในพื้นที่ใกล้ประเทศไทย
-ขนาดแผ่นดินไหวสูงสุด

ข้อมูลสำหรับพื้นที่นิคมอุตสาหกรรม

น้ำท่วมและน้ำป่าไหลหลาก

ตรวจสอบพื้นที่น้ำท่วมจากดาวเทียมและพื้นที่เสี่ยงน้ำป่าไหลหลาก

แผนที่น้ำท่วม GISTDAคาดการณ์น้ำป่า

ฝนตกหนัก พายุ และคลื่นลมแรง

ตรวจสอบประกาศเตือนภัย ภาพเรดาร์ และเส้นทางพายุล่าสุด

กรมอุตุนิยมวิทยาเรดาร์และแผนที่

แผ่นดินไหวและสึนามิ

ตรวจสอบรายงานแผ่นดินไหว สึนามิ และประกาศเตือนภัยอย่างเป็นทางการ

รายงานแผ่นดินไหวศูนย์เตือนภัย ปภ.

ไฟป่า จุดความร้อน และหมอกควัน

ตรวจสอบจุดความร้อน ไฟป่า และพื้นที่หมอกควันจากข้อมูลดาวเทียม

แผนที่ไฟป่า GISTDAรายงานจุดความร้อน

ภัยแล้งและสถานการณ์น้ำ

ตรวจสอบสถานการณ์น้ำ พื้นที่เสี่ยงภัยแล้ง และรายงานล่าสุด

แดชบอร์ด GISTDAรายงาน ThaiWater

ประกาศเตือนภัยและเหตุฉุกเฉิน

ตรวจสอบประกาศเตือนภัยและรายงานสถานการณ์ประจำวันจาก ปภ.

ประกาศเตือนภัย ปภ.สถานการณ์ประจำวัน

แนวทางการตรวจสอบและการปฏิบัติเบื้องต้น

สำหรับผู้ประกอบการ

  1. ตรวจสอบสถานการณ์ล่าสุดและประกาศจากหน่วยงานภาครัฐ
  2. ประเมินความเสี่ยงต่อพนักงาน อาคาร ระบบสาธารณูปโภค และกระบวนการผลิต
  3. ทบทวนแผนฉุกเฉิน เส้นทางอพยพ และช่องทางติดต่อภายในองค์กร
  4. แจ้งเจ้าหน้าที่นิคมอุตสาหกรรมเมื่อพบเหตุผิดปกติหรือได้รับผลกระทบ

สำหรับเจ้าหน้าที่

  1. ยืนยันข้อมูลกับหน่วยงานต้นทางและตรวจสอบพื้นที่ที่อาจได้รับผลกระทบ
  2. ประสานผู้ประกอบการและหน่วยงานที่เกี่ยวข้องตามระดับความรุนแรง
  3. ติดตามสถานการณ์อย่างต่อเนื่องและบันทึกลำดับเหตุการณ์
  4. เผยแพร่คำแนะนำหรือประกาศอย่างเป็นทางการผ่านช่องทางที่กำหนด

ข้อมูลในหน้านี้ใช้เพื่อสนับสนุนการเฝ้าระวังเบื้องต้น ควรตรวจสอบประกาศอย่างเป็นทางการจากหน่วยงานที่รับผิดชอบก่อนตัดสินใจดำเนินการทุกครั้ง

แหล่งข้อมูลอ้างอิง: GISTDA, ThaiWater, กรมอุตุนิยมวิทยา และกรมป้องกันและบรรเทาสาธารณภัย (ปภ.)
